# Subtitle Study Modes — 字幕学习模式

当用户只想从已有字幕文件中学习/提取知识点（而非全流程课程导入到 Obsidian），使用以下模式之一。

## 前置判断

| 用户场景 | 文件类型 | 建议模式 |
|---------|---------|---------|
| "帮我学习这个视频"、"总结一下" | .srt / .vtt | A: 知识提取（默认） |
| "帮我出几道题" | .srt / .vtt | C: 测验生成 |
| "这个视频讲了什么" | .srt / .vtt | B: 章节摘要 |
| "帮我整理术语"、"词汇" | .srt / .vtt | D: 关键词汇 |
| "考考我" | .srt / .vtt | E: 交互式问答 |

## 模式 A: 知识提取（默认）

生成结构化学习指南：

```
# 课程标题 / 主题
## Chapter 1: <章节名>
### Key Concepts
- ...
### Important Definitions
- ...
### Key Takeaways
- ...
### Examples / Demonstrations
- ...
...
### Glossary
- term: definition
```

## 模式 B: 章节摘要

按主题跳转将字幕分组为逻辑章节，每章 2-3 句总结。检测主题变化的信号：

- 重复出现的技术术语
- "Now let's talk about..." / "接下来我们来看" 类过渡语
- 字幕时间轴超过 3 秒的静默间隔
- 问题-回答模式的结束

## 模式 C: 测验生成

根据字幕内容生成交互式测验题：

- **选择题**：4 个选项 + 正确答案
- **填空题**：关键词留空
- **判断题**：True/False
- **简答题**：提示回答方向

交互方式：逐题提问 → 用户回答 → 揭示答案并解释。

## 模式 D: 关键词汇

提取术语句汇表：

```
| 术语 | 翻译 | 上下文解释 |
|------|------|-----------|
| KV Cache | 键值缓存 | 在 Transformer 推理中缓存注意力机制的中间结果 |
| ... | ... | ... |
```

## 模式 E: 交互式问答

将内容呈现为交互式问答。基于材料提问，提供提示，解释正确答案。

## 常见陷阱

1. **非常大的字幕文件**（3000+ 行）— 分段阅读而非一次性加载
2. **自动生成字幕** — 含有误听错误（如 "Karpathy" → "Endocarpathy"），标记明显的转录错误
3. **混合语言视频** — 常见于技术教程中英混用，保持原文同时在必要时翻译
4. **视觉依赖内容** — 代码演示/图表在字幕中没有体现，标记"此处为视觉内容"
5. **多说话人** — 自动字幕可能搞混说话人，注意区分

## 验证清单

- [ ] 字幕文件正确加载解析（时间戳已去除）
- [ ] 学习材料覆盖了字幕中所有主要话题
- [ ] 生成内容忠于原始材料
- [ ] 测验题可从字幕内容回答
- [ ] 术语提取准确
- [ ] 用户选择的学习模式正确应用
