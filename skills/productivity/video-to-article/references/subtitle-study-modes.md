# 字幕深度学习 — 5种模式详解

## 模式选择决策树

```
用户有字幕/视频 → 用户想做什么？
  ├─ "总结一下"/"讲了什么" → B1: 知识提取
  ├─ "分章节"/"有哪些部分" → B2: 章节摘要
  ├─ "术语"/"词汇" → B4: 关键词汇
```

## B1: 知识提取输出格式

```markdown
# <视频标题>
## Chapter 1: <章节名>
### Key Concepts
- 概念1：解释
### Key Takeaways
- 核心结论1
### Examples / Demonstrations
- 示例1：说明

### Glossary
| 术语 | 解释 |
|------|------|
```

## B2: 章节摘要

检测主题切换的信号：
1. 演讲者的过渡语："Now let's talk about..."、"接下来..."
2. 字幕时间轴上超过5秒的间隔（长停顿 = 话题转换）
3. 新术语/概念的大量出现
4. 显式的序号/编号（"第一点...第二点..."）

每章输出格式：
```markdown
## Chapter N: <自动推断的章节名>
### 时间范围：00:00 - 05:30
### 核心内容：2-3句话总结
### 关键点
- 点1
```

## B3: 关键词汇表

提取标准：领域专有名词、出现3次以上术语、明确定义的词汇、缩写全称。
输出：| 术语 | 中文/翻译 | 上下文解释 | 出现位置 |

## 字幕质量处理

| 问题 | 处理 |
|------|------|
| 人名误听 | 标记 `[可能的转录错误]` |
| 技术术语拆分 | 合并为正确术语 |
| 中英混排 | 保持原文 |
| 多说话人混杂 | 标注 `[可能为多人对话]` |
| 纯视觉内容 | 标注 `[此处为视觉内容]` |
